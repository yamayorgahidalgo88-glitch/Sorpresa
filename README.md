# Ayoub Lahmany Barber Shop · Alcorcón

Web de la barbería de Ayoub. Las reservas van a [Booksy](https://booksy.com/es-es/86074_ayoub-lahmany-barber-shop_barberia_52935_alcorcon).

## Qué hay

| Ruta | Qué es |
|---|---|
| `index.html`, `assets/` | La web: HTML, CSS y JavaScript sin framework ni compilación |
| `assets/js/motion.js` | Animaciones al hacer scroll (GSAP, ScrollTrigger y Lenis) |
| `assets/js/reel.js` | Carrusel infinito de cortes reales |
| `flores/` | La página de las flores amarillas que había antes, intacta |

## Probar en local

```bash
npm run dev   # http://localhost:3000
```

## Publicar en Vercel

Ver `HANDOFF.md`: se publica con `create_deployment` desde la rama, porque Vercel no está enlazado al repositorio.
